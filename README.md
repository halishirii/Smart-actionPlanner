# NOVA — نووا

دستیار اکشن‌پلن ویزیت + آرشیو ۴٬۱۰۴ پزشک. نسخه‌ی آنلاین (GitHub Pages) و نصب‌پذیر روی گوشی (PWA).

## فایل‌ها
- `index.html` — برنامه
- `db.js` — آخرین دیتابیس (با شماره‌ی نسخه و تاریخچه‌ی تغییرات)
- `config.js` — تنظیمات؛ ایمیل دکمه‌ی «گزارش باگ / پیشنهاد» (جای `__FEEDBACK_EMAIL__` را عوض کنید. تا عوض نکنید دکمه نمایش داده نمی‌شود)
- `manifest.webmanifest`, `sw.js`, `icon-*.png` — نصب روی گوشی و کار آفلاین بعد از اولین بازدید

## انتشار
۱. همه‌ی فایل‌ها را در مخزن گیت‌هاب بگذارید (ریشه‌ی مخزن).
۲. Settings ← Pages ← Source: «Deploy from a branch» ← شاخه‌ی main، پوشه‌ی root.
۳. آدرس `https://USERNAME.github.io/REPO/` آماده است.

## به‌روزرسانی دیتابیس برای همه
۱. در برنامه ویرایش‌ها را انجام دهید (روی نام پزشک بزنید ← ویرایش اطلاعات ← تأیید).
۲. تب «نسخه‌ها» ← «دانلود دیتابیس جدید (db.js)» (و اگر خواستید اکسل با شیت «تغییرات»).
۳. فایل `db.js` را در مخزن جایگزین کنید (Add file ← Upload files). از دفعه‌ی بعد همه نسخه‌ی جدید را می‌بینند.

نکته: ویرایش‌هایی که کاربران روی مرورگر خودشان انجام داده‌اند و در `db.js` منتشرشده نیست، روی نسخه‌ی جدید اعمال نمی‌شود؛ برنامه این را اعلام می‌کند و اکسل همان تغییرات را می‌دهد.
